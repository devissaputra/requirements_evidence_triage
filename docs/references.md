# References and Data Sources

## Gold standard benchmark

Hey, T. (2023). *Dataset for Requirements Classification in Traceability Link Recovery Datasets*. Zenodo. Version DOI: 10.5281/zenodo.7867846. Concept DOI: 10.5281/zenodo.7867845.

The dataset provides gold standard classifications for requirement parts across five traceability link recovery benchmark datasets, including eTour.

## How the literature is used

The Hey, Keim, and Corallo study motivates requirements classification as an input to traceability link recovery.

The broader requirements classification literature motivates label level evaluation.

Human in the loop literature motivates the separate question of allocating human review.

This repository does not claim to reproduce the complete FTLR study or to introduce a state of the art triage algorithm.
