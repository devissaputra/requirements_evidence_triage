# Research Package Definition

This repository qualifies as a research package because a requirements engineering decision problem is connected to a pinned empirical benchmark, complete derived evidence, executable evaluation, explicit leakage controls, review routing analysis, reproducibility checks, scientific figures, and bounded interpretation.

## Core research problem

How should limited human review capacity be evaluated when automatic requirements classification errors are heterogeneous?

## Empirical core

Five label classification evaluation plus oracle and prediction only review allocation analysis over 571 eTour requirement elements.

## Scientific safeguard

The gold aware 51.9% top 100 result is an oracle upper bound.

The operational result is the prediction only queue, which captures 21.5% of label errors in 100 reviewed items compared with 17.5% expected under uniform random review.

## Required evidence chain

A release is complete only when these agree:

- pinned source identity;
- complete derived evidence;
- classification metrics;
- triage curves;
- code;
- tests;
- source rebuild;
- figures;
- scientific report;
- paper blueprint;
- leakage boundary;
- validity statements.

## Boundary

The package is a benchmark study, not a claim of production ready or optimal review routing.
